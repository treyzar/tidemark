Tidemark — нативный остров для рабочего стола Windows.

В релиз вошли:

- Новый логотип и иконки приложения и трея, два прибрежных фона.
- Настройки с четырьмя разделами и превью оформления.
- Курсор-рука на кнопках, плавная подсветка при наведении, движение переключателей и появление окна. Эффекты учитывают настройки анимаций Windows.
- Поиск через Google с обновлением прежнего стандартного адреса Яндекса.
- Исправление чёрного содержимого вкладки «Текст» при первом входе.
- Исправление сборки ресурсов в путях GitHub Actions вида `D:\a\...`.

**Установка:** скачайте `tidemark-1.1.1-setup.exe` либо распакуйте `tidemark-1.1.1-win-x64.zip` и запустите `win-island.exe`.

Windows 10 (2004) или новее; рассчитано на Windows 11. Исполняемые файлы не подписаны.

Проверки: 122 теста приложения успешно, 8 пропущены; дополнительный тест путей ресурсов успешно.
