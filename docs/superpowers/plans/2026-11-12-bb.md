# bb connection implementation plan

**Goal:** Answer agents and send follow-ups from Tidemark.
**Architecture:** Independent bb plugin HTTP API, authenticated native Windows client, island question notifications and native compose panel.
**Spec:** ../specs/2026-11-12-bb-design.md

## Constraints and review focus

No automatic answers; preserve full question content in the panel; reject stale answers, invalid choices, and blank messages; keep tokens out of logs and repository; require TLS remotely; keep network work off the island UI thread; retain unsent drafts on failures.

- [x] Implement and test the plugin request validation and SDK adapter; expose bounded authenticated routes.
- [x] Implement and test the native connection model and URL validation; add connection and compose panel, island notifications and entry points.
- [x] Document installation, package the plugin separately, build and validate both components.
- [ ] Verify live workflow, publish commits and downloadable release artifacts, verify GitHub results.
