# bb

Установите отдельный плагин в bb:

```powershell
bb plugin install git:https://github.com/treyzar/bb-plugin-tidemark.git
```

На компьютере с Tidemark запустите `Connect-Bb.ps1` из этой папки. Скрипт использует локальный bb CLI, получает токен без его вывода и сохраняет его зашифрованным для вашей учётной записи Windows.

Либо откройте контекстное меню пустой области острова → **bb · вопросы и сообщения…** (также в трее или `win-island.exe --bb`). Введите адрес bb и токен из `bb plugin token tidemark`, нажмите **Подключить**. Для удалённого сервера нужен HTTPS. Сервер bb и плагин могут работать на другом компьютере.

Новый вопрос появляется на острове. Кнопка **Ответить** открывает полный вопрос, варианты ответа и поле своего текста. Несколько вопросов заполняются по очереди и отправляются вместе. Для дополнения задачи выберите тред и **Дополнить задачу**.

Полный запрос разрешения показан в панели; доступны только разовое разрешение и отказ. Запросы расширенных прав и нестандартные формы открывайте в bb. Автоматических ответов и разрешений нет.

**Позже** скрывает уведомление, сохраняя вопрос в панели. **Обновить** перечитывает вопросы. При сбое отправки черновик остаётся: перед повторной отправкой проверьте тред, чтобы не отправить сообщение дважды.

Подключение хранится отдельно в `%APPDATA%\win-island\bb-connection.json`; токен защищён Windows DPAPI. Файл нельзя переносить другому пользователю — подключитесь заново. **Отключить** удаляет подключение. Для доступа только к одному проекту выберите проект в настройках плагина Tidemark в bb.

Плагин и подробная инструкция: https://github.com/treyzar/bb-plugin-tidemark
